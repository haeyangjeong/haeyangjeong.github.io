# 정해양 포트폴리오 홈페이지

2D & 3D 게임 아티스트 정해양의 포트폴리오 사이트입니다. Canva 포트폴리오("취업포폴PDF용")의 내용과 이미지를 바탕으로 만든 한 페이지짜리 정적 사이트이며, 빌드 과정 없이 HTML·CSS·JS 파일만으로 동작합니다.

## 페이지 구성

| 순서 | 섹션 | 내용 |
|---|---|---|
| 1 | 표지 (Main) | "Portfolio" 제목, 캐릭터 일러스트, 프로젝트·프로필 이동 버튼 |
| 2 | Profile | 이름, 증명사진, 이메일·전화번호, 학력·경력·사용 툴 카드 |
| 3 | Project | 프로젝트 6개 버튼 한 줄, 누르면 정보와 작업물이 그 자리에 표시 |
| 4 | Activity | 영상편집·굿즈 제작·현수막 제작 버튼, 누르면 작업물이 그 자리에 표시 |

상단에는 고정 메뉴(Profile / Project / Activity)가 있고, 넓은 화면에서는 왼쪽에 반투명 유리 느낌의 바로가기 버튼이 따라다닙니다.

## 디자인

블루 아카이브 공식 홈페이지의 구성과 분위기를 참고했습니다. 넥슨의 로고나 이미지는 쓰지 않았고, 그림은 모두 본인 작업물입니다.

- **색**: 흰색과 하늘색 바탕에 파란색(`#128afa`) 강조. 글자 등 어두운 색은 남색 대신 갈색 톤 블랙(`#2b2420`)을 씁니다.
- **글꼴**: 제목·버튼·라벨 등 굵은 글씨는 여기어때 잘난체 고딕, 본문은 Noto Sans KR.
- **글자 크기**: 데스크톱에서 모든 글자가 24px 이상입니다. 좁은 화면(860px 이하)에서는 본문 20px, 상단 메뉴 15px로 줄어듭니다.
- **모양**: 버튼과 라벨은 기울어진 평행사변형, 이미지 틀은 모서리가 둥근 사각형에 아래쪽 그림자.
- **숫자 강조 없음**: 번호나 큰 숫자 장식을 쓰지 않고, 제작기간은 정보 표 안에만 나옵니다.

## 파일 구조

```
portfolio-site/
├── index.html      페이지 뼈대와 Profile 내용
├── style.css       전체 스타일
├── main.js         Project·Activity 데이터와 버튼 동작
└── assets/
    ├── profile.jpg 증명사진
    ├── thumbs/     프로젝트 대표 이미지 6장
    └── slides/     작업물 이미지 17장 (Canva 페이지 번호가 파일명)
```

## 내용 고치는 법

- **프로젝트 추가·수정**: `main.js` 맨 위의 `PROJECTS` 배열을 고칩니다. `key`는 `assets/thumbs/<key>.jpg` 파일명과 같아야 하고, `slides`에는 `assets/slides/` 안의 파일 번호를 적습니다.
- **활동 추가·수정**: `main.js`의 `ACTIVITIES` 배열을 고칩니다.
- **프로필·연락처**: `index.html`의 `id="profile"` 섹션을 고칩니다.
- **색·글꼴·크기**: `style.css` 맨 위 `:root`의 변수를 고칩니다.

## 배포 (GitHub Pages)

아직 배포하지 않았습니다. 순서는 다음과 같습니다.

1. GitHub에서 빈 공개 저장소를 만듭니다. 이름을 `아이디.github.io`로 하면 주소가 `https://아이디.github.io`가 됩니다.
2. 이 폴더에서 원격 저장소를 연결하고 푸시합니다.
3. 저장소의 Settings → Pages에서 Branch를 `main`으로 지정합니다.

배포하면 증명사진과 전화번호가 공개 웹에 올라갑니다.
